# NurdaMotion Portfolio

Live site: https://nurdamotion.vercel.app/

Buildless HTML, CSS and JavaScript, deployed through the existing `nurdamotion` Vercel project. `index.html` contains the page and interactions; `media/` contains five web-optimized films and posters. The fourteen original Vimeo works remain in the archive.

Share `/?focus=wellness#work` for the fitness-first selection or `/?focus=marketing#work` for the product/ad selection. Filters narrow the featured films independently of this ordering.

The supplied October 2026 creative CV is available at `/resume.pdf`. Video masters remain outside this repository. Web copies use H.264/AAC, preserve aspect ratio and frame rate, and include faststart metadata. Approved empty sections were removed from the Aviasales and Qoldau copies.

Environment files, Git state and Vercel credentials are excluded from deployment. No installation or build step is required.
